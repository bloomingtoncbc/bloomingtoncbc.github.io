We use a mailing list for announcements, so that I don't have to BCC dozens of people every time. Because of the large number of participants in our count circle, I won't be able to manage email addresses or send information about the CBC on an individual basis, so please follow the self-serve instructions below.

Note that this is not a discussion group. It's only for email announcements from the circle coordinator. You don't need to access the group on the website. You won't receive messages from other members, and they won't be able to see your email address. You can unsubscribe (see below) if you leave our CBC.

### Subscribe to the mailing list

If you're not already a member of the mailing list, please subscribe so you can receive announcements (it's hosted on Google Groups, but you don't need a gmail address or Google account to join.) Here are the steps:

- Send an empty email to [bloomingtonmncbc+subscribe@googlegroups.com](mailto:bloomingtonmncbc+subscribe@googlegroups.com).
- You'll receive a reply back with the subject "Join request for bloomingtonmncbc" (make sure to check your spam/junk folder!) which says:

  > We received your request to join bloomingtonmncbc.
  >
  > bloomingtonmncbc requires owner approval for join requests. If you would like to continue with your join request, reply to this email or click below

- All you need to do is hit "reply" and then I'll see the pending member request so I can approve you.
  - If you have any technical difficulties signing up, please let me know and I will try to add you directly.
- When it's approved you'll start receiving group announcements by email.
  - Note that you won't need to access the group via the web, this is only used for group-wide announcements that you will receive via email.

### Unsubscribe from the mailing list

Simply send an empty email to [bloomingtonmncbc+unsubscribe@googlegroups.com](mailto:bloomingtonmncbc+unsubscribe@googlegroups.com).

### Update your email address

If you have changed email addresses, all you need to do is unsubscribe using the old email, and resubscribe with the new one, following the same steps as above. It's important to keep your address current for this list. Make sure that you are using the same address that you are using to fill out the participant survey, otherwise it's difficult for me to keep track of participants.
