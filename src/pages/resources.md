Here are some links to resources that might be helpful and/or interesting!

## CBC Resources

- [Audubon Christmas Bird Count FAQ](https://www.audubon.org/answers-your-top-questions-about-christmas-bird-count)
- [Audubon map of active count circles](https://gis.audubon.org/christmasbirdcount)
  - See ALL the count circles
- [Audubon live interactive CBC map](https://gis.audubon.org/cbclive)
  - You can submit photos and see what other CBCs are doing
- [MOU Bloomington Count Circle page](https://moumn.org/CBC/locations.php?cid=157)
- [MOU CBC calendar](https://moumn.org/CBC/cal/calendar.php)
  - See all the CBCs in our state
- [Audubon CBC Field Protocol Quick Start Guide](https://drive.google.com/file/d/1ZbZpD25_F-bHX_aJFr6vp8tZ0P_15qvv/view?usp=sharing)
  - Tips on how to count for Feeder Watchers and Field Counters.
- [Field Counter Cheat Sheet](https://view.publitas.com/birds-canada-gykxaz9yrrpp/field-counters-guide-to-cbc_cheat-sheet-with-datasheet/page/1)
- [Feeder Counter Cheat Sheet](https://view.publitas.com/birds-canada-gykxaz9yrrpp/feeder-counters-guide-to-cbc_cheat-sheet-with-datasheet/page/1)
- [eBirding during the CBC](https://ebird.org/news/ebirding-on-christmas-bird-counts)
  - This is NOT a substitute for submitting a count sheet.
